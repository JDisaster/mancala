# mancala

Team project for building the Mancala board game in Java using Swing




                    Development Schedule
 
 Week 1 | Project setup and basic structure |
 
 Week 2 | Build game logic (model) |
 
 Week 3 | Create GUI (view) |
 
 Week 4 | Connect model and view (controller) |
 
 Week 5 | Add styles, test, and finish project |


 

                   Structure   

src/model        - game logic classes  

src/view         - GUI components  

src/controller   - connects model and view  

src/style        - board style  

src/MancalaMain.java - program entry point
